# Artefatos de cards

Cada card possui uma pasta em `qa/cards/<CARD>/` com contexto Jira/Confluence,
BDD revisável, plano Zephyr, decisão de automação e descrição simulada ou real
do PR.

Os BDDs aprovados e os documentos de decisão são versionáveis. Respostas brutas
de APIs, credenciais, tokens, screenshots, vídeos e traces não pertencem a esta
pasta.
