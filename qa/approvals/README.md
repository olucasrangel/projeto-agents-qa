# Aprovações do fluxo de QA

Os registros ficam em `qa/approvals/<CARD>/`:

- `G1-bdd-approval.md`: aprovação dos cenários;
- `G2-zephyr-approval.md`: aprovação do plano/publicação Zephyr;
- `automation-decision.md`: seleção de automação por cenário;
- `G3-execution-delivery-approval.md`: aprovação do relatório, evidências e entrega;
- `executions/<runId>/`: resumo sanitizado e manifesto de evidências.

Os binários de evidência ficam em `evidence/`, que não é versionado.
