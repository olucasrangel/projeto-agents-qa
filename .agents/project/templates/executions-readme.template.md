# Execuções — {CARD}

Cada execução real ou simulada recebe uma pasta `<runId>/` contendo:

- `execution.md`: resumo sanitizado;
- `evidence-manifest.json`: vínculo entre cenário, chave VPOS e screenshot;
- referência ao ciclo de teste Zephyr.

Os screenshots, vídeos e traces permanecem em `evidence/` e não são versionados.
